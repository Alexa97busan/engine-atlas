# 르노코리아 엔진 도감

자동차산업기사 학습용 정적 웹사이트입니다. 빌드 과정이 없어 `index.html`을 브라우저로 열면 바로 동작합니다.

- `index.html` 화면 구조 (탭: 엔진별 / 차종별 / 연식별 제원표 / 형식명 읽기 / 퀴즈)
- `style.css` 디자인 토큰(라이트/다크), 트랜지션
- `data.js` 데이터. 엔진 `E`, 차종 `MODELS`, 제원표 `TBL`
- `app.js` 탭, 필터, 검색, 퀴즈 동작
- `check.js` 데이터 형식 검사 (`node check.js`)

## 제원표 행 추가

`data.js` 맨 위 주석에 형식이 있습니다. 출처(14번째 칸)를 비워 두면 사이트에 "확인 필요"로 표시됩니다.

    ["SM7 (L47 VQ25DE)", "2011~2019", "VQ25DE", "2.5L V6", "190", "24.8", "X", "6AT", "10.2", "", "SM7", "", "", "https://..."]

함께 작업하는 방법은 `CONTRIBUTING.md`를 보세요.

## 확인용 실행

    python3 -m http.server 8000

브라우저에서 localhost:8000 으로 접속합니다.

## 공유 (GitHub Pages)

https://alexa97busan.github.io/engine-atlas/ 에서 볼 수 있습니다. `main`에 합쳐진 변경은 1분 안팎으로 자동 반영됩니다. (설정: 저장소 Settings → Pages → Branch `main` / `(root)`)

## 출처

엔진 설명과 차종 정보는 나무위키, 위키백과, 언론 보도를 대조해 정리했습니다. 제원은 학습 참고용이며, 정비 작업은 반드시 해당 차종의 정비지침서 값을 따르세요.
